# 태양광 배치분석 — 웹 버전

`태양광분석어플/app/src/main/assets` 의 **복사본**이다. 여기서 직접 고치지 말고 어플 쪽을 고친 뒤
`태양광분석어플/web동기화.sh` 를 돌린다. 깃허브 페이지(Settings > Pages > main / root)로 서빙한다.

웹에서는 `window.Native` 가 없으므로:
- V-World 는 JSONP 로 호출 → **이 페이지 도메인(`https://<계정>.github.io`)이 V-World 인증키 URL 에 등록돼 있어야** 건물이 나온다.
- 카카오 지도도 JS SDK 도메인에 같은 도메인을 등록해야 뜬다.
- 메일은 첨부가 안 되므로 리포트·명함 PNG 두 장을 내려받고 메일 작성창만 연다.

키(`config.js`)가 그대로 들어 있다. 카카오 JS 키·V-World 키는 도메인으로 묶이는 클라이언트 키라 공개돼도
다른 사이트에서 못 쓰지만, 서명키 비밀번호 같은 건 여기 없다 — 그래서 이 저장소만 공개(Pages 용)로 둘 수 있다.
